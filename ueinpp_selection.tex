Two sets of events are selected for analysis: first, an event selection for inclusive R=0.4 jet studies and second, an event selection for R=0.4 exclusive dijet studies.

The inclusive R=0.4 jet study event selection is as follows: 
\begin{itemize}
    \item $|z_{vtx}| <$ 60 cm
    \item Jet 10 trigger
    \item $N_{jet} \geq 1$
    \item Leading jet $\|\eta\| <$ 0.7
    \item Leading jet calibrated $\pT >$ 21 GeV, truth $\pT >$ 17 GeV
    \item Transverse region reconstructed $\Sigma E_{T} \in [-1.08, 20]$ \GeV, truth $\Sigma E_{T} \in [0, 35]$ \GeV{}
\end{itemize}

The R=0.4 exclusive dijet study event selection has the same criteria as the inclusive study, with additional event-level requirements including: 
\begin{itemize}
    \item $N_{jet} \geq 2$
    \item Subleading jet $\pT >$ 0.3* Leading jet \pT{} (for both calibrated and truth jets)
    \item Leading and Subleading jet with $\|\Delta\phi\| >$ 3$\pi$/4
    \item Subleading jet with $\|\eta\| <$ 0.7
    \item No additional jets with $\pT >$ 0.5* Leading jet \pT{} and $\|\eta\| <$ 0.7
\end{itemize}

An additional cut on the final set of runs used for the analysis is applied following the results found from pileup studies included in Section~\ref{sec:ueinpp_pileup}. 
This additional cut is to only include runs with low-to-moderate average pileup. 
Details on how this pileup rate is determined and corrections on the observable from pileup are also included in Section~\ref{sec:ueinpp_pileup}.
Combining all these selections including the low pileup run requirement, this analysis analyzes an integrated luminosity of 34 pb$^{-1}$.
