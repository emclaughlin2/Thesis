Analysis codebase is comprised of three parts, a treemaking module which outputs reconstructed and truth jet, calorimeter tower, primary G4truth particle and calorimeter topocluster information from events passing the event selection criteria outlined in Section \ref{sec:selection}, second a Fun4All macro for running over both data and monte carlo datasets and finally a directory with analysis macros. This codebase is currently located at \url{https://github.com/emclaughlin2/sPHENIX-analysis/tree/ue_in_pp}.
