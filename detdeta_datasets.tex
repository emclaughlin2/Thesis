A set of runs from one store during the physics quality RHIC Run 2024 \auau collision period were used for this analysis. 
These runs were selected based on high calorimeter and global detector data quality.
The calorimeters had a limited set of bad channels for runs in this store (>98\% good channels in the EMCal and >99\% good channels in the HCals).
The channel-by-channel calorimeter timing was also checked for good timing performance and stability across runs in this store.
The global detectors (MBD + ZDC) also had high data quality and were used for centrality determination for each run in the store. 
One store was used for first analyses of the Run 2024 Au+Au data because there was no statistical limitation and it allowed for more focused data quality checks with finite personnel and computing resources. 
Note cross checks on the calibration using different stores from the Run 2024 Au+Au data period have been performed and show consistent results. 

Data was collected using a hardware-level minimum-bias trigger requiring at least two PMTs on each side of the MBD detector to fire.
The minimum bias trigger during these runs had high live time and low prescale factors, resulting in a large sample of minimum bias events for this analysis.
A set of offline-selection criteria was also applied to the data to remove events consistent with beam-related backgrounds and non-hadronic interactions.
More details on the minimum bias trigger and event selection used for this analysis is outlined in Section~\ref{sec:detdeta_selection}.

Three MC generators are used for comparison to data and for deriving correction factors mapping the reconstructed \detdeta distributions back to the truth particle level \detdeta. 
1 million minimum bias \auau events at \snn = 200 GeV were used from each generator, \hijing~\cite{hijing}, \ampt~\cite{ampt}, and \epos~\cite{epos}.
These events were then passed through the full sPHENIX detector \geant~\cite{GEANT4} simulation and reconstruction to produce simulation datasets that can be compared directly to data.
The MC events are also reweighted to match the z-vertex distribution in data and the particle composition in previous \auau measurements at \snn = 200 GeV. 
More details on the MC sample reweighting for this analysis is included in Section~\ref{sec:detdeta_mcsamples}.
