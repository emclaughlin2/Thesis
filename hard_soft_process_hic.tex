For jet events in nucleus-nucleus collisions, there is a hard scattering as well as additional processes that occur within the collisions including:
Multiple parton interactions
Radiation from initial or final state partons of the collision
Color connections with beam remnant partons prior to hadronization
These processes all contribute to the underlying event of a jet event and need to be subtracted from the final state jet measurements to accurately trace jet measurements back to initial hard scatterings
To study the underlying event in jet events, we can divide calorimeter geometry into 4 sections in $\phi$ with respect to the hard scattering reference (highest pT particle or jet)
Transverse sections should have little influence from hard scattering allowing for direct measurements of the underlying event 
It has been suggested from underlying event measurements made by CMS using the ratio of \detdeta from UE to \detdeta in MB events at forward rapidity, that the correlation between the underlying event and the leading jet pT may be collision energy dependent (results from measurements at 0.9, 2.76 and 7 TeV)
In addition to being able to measure the underlying event using \ET, many detectors, including ATLAS (top) and STAR (bottom) shown here, have measured the underlying event using the charged particle multiplicity density, \dNchdeta, as a function of the leading jet pT. 
\dNchdeta as a function of leading charged particle pT at LHC energies has shown an increase and then plateau for the transverse region, while \dNchdeta decreases as a function of leading jet pT at RHIC energies
This discrepancy can be studied with the sPHENIX calorimeters using \detdeta  as a function of the leading jet pT, employing the \detdeta measurement machinery to make measurements of the underlying event in p+p collisions at RHIC energies
